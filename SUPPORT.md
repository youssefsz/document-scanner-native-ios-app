# Support

Choose the channel that matches the problem so it reaches the right place.

## App help

For help using DocScanner, purchases, or App Store builds, visit [DocScanner Support](https://youssef.tn/DocScanner/support/) or email [dhibi.ywsf@gmail.com](mailto:dhibi.ywsf@gmail.com). Include the app version, device model, and iOS or iPadOS version. Do not send scanned documents, passwords, purchase credentials, or encryption keys.

## Bugs in this repository

Search the [existing issues](https://github.com/youssefsz/document-scanner-native-ios-app/issues), then open a bug report with the provided template. GitHub issues are public. Use synthetic documents and remove personal information from screenshots and logs.

## Security vulnerabilities

Follow [SECURITY.md](SECURITY.md) and report the issue privately. Do not disclose a suspected vulnerability in a GitHub issue or discussion.

## Feature requests

Open a feature request and describe the problem before proposing an interface or implementation. Requests are considered against the app's local-first privacy model and maintenance cost.
